# 🚀 NovaLaunch — Bootstrap Responsive Landing Page

NovaLaunch is a modern, responsive landing page designed for a product-launch and growth platform.

The website helps individuals and teams organize ideas, plan projects, collaborate efficiently, and understand their growth through a clean and responsive interface.

---

## ✨ Features

- 🚀 Modern product landing page
- 📱 Fully responsive design
- 🧭 Responsive Bootstrap navigation
- 🎯 Hero section with call-to-action buttons
- 📊 Dashboard preview
- 🔘 Bootstrap button showcase
- 📋 Smart Planning
- 👥 Fast Collaboration
- 📈 Growth Analytics
- 🎞️ Interactive Bootstrap carousel
- 💰 Pricing plans

- 🎉 Success message after form validation

## 📩 Contact Form

The contact section contains fields for:

* Full Name
* Email
* Subject
* Message

The form uses Bootstrap validation and JavaScript to validate user input.

### Form Flow

```text
User submits form
       ↓
Prevent default submission
       ↓
Apply validation
       ↓
Check form validity
       ↓
   ┌───┴───┐
   ↓       ↓
 Invalid  Valid
   ↓       ↓
Show      Show success
errors    message
            ↓
        Reset form
            ↓
     Hide message after
        5 seconds
```

## 💻 Run Using VS Code

For the best development experience:

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.
